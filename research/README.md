# Discovery protocol

The work proceeds in this order:

1. map existing concepts and their scope;
2. generate diverse candidates without treating them as discoveries;
3. score and cull in successive generations;
4. run synonym, conceptual-equivalence, and cross-disciplinary prior-art search;
5. preserve prosecution and defense arguments;
6. formalize and propose tests only for survivors;
7. select a framework only after independent review.

The repository deliberately separates `KNOWN`, `DERIVED_HERE`, `PROPOSED_HERE`,
and `UNKNOWN` epistemic statuses.
