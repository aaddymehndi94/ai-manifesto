# D4:I301: Distinguish permission acquisition from provider-created exception costs at equal task quality.

Research-only; PRIOR_ART_CHALLENGED_LIMITED_INSPECTION.

## Proposition

If a provider optimizes completed tasks while charging human exception work outside its task metric, policies that create avoidable exception work can make wider permission rational for the user even when a narrower policy has the same completion quality.

## Strongest interpretation

Holding successful task output and inherent approval requirements fixed, a policy that shifts coordination work to the user can increase rational additional delegation. Test whether charging that work to provider performance changes policy selection without rewarding permission directly.
