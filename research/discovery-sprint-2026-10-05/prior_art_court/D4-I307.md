# D4:I307: Truthful independent evidence may remain beneficiary-selected.

Research-only; PRIOR_ART_CHALLENGED_LIMITED_INSPECTION.

## Proposition

If a provider selects which expensive cases receive an independent audit under a fixed audit budget, completely truthful audited results can favor renewal when selection excludes cases whose wider effects matter most to the authorization decision.

## Strongest interpretation

Independent audit execution is insufficient for independent audit coverage when the beneficiary allocates a fixed budget. Compare risk-stratified externally fixed sampling with provider-selected sampling at equal audit quality.

Emir Kamenica, Matthew Gentzkow (2011). Prior proposition, paraphrased: A sender can choose an information structure that benefits it through a rational receiver’s action without false messages.

Inspection: Publisher abstract and bibliographic record.

- same variables: Yes abstractly: sender-selected information and receiver choice.
- same causal structure: Independent truthful signal realization can coexist with beneficiary choice of experiment.
- same beneficiary: Sender benefits from receiver action.
- same outcome: Decision influence; grant is an application.
- same timescale: Single evidence/action episode.
- same prediction: Independent execution does not make experiment choice disinterested.
- same intervention: Change feasible experiment choice or information obligations.

### D4:S015: [Competition in Persuasion](https://web.stanford.edu/~gentzkow/research/BayesianComp.pdf)

Matthew Gentzkow, Emir Kamenica (2017). Prior proposition, paraphrased: Competition need not improve information. A condition on feasible experiments determines when more informative outcomes are guaranteed; sequential and costly information introduce further limits.

Inspection: Primary PDF pages1–6: opening counterexample, model, assumptions, Blackwell-connectedness.

- same variables: Yes abstractly: competing senders and feasible information.
- same causal structure: Information environment constrains what independent parties can reveal.
- same beneficiary: Senders and receiver.
- same outcome: Information quality and receiver welfare.
- same timescale: Simultaneous game, extensions discussed.
- same prediction: Adding parties need not improve information in a constrained environment.
- same intervention: Expand feasible independent experiments; assumptions are critical.

## Subtraction

KNOWN: Experiment selection and signal realization are distinct. Honest evaluation of selected cases does not certify unselected coverage.

NEW RESIDUE: Factor audit routing independence separately from audit execution independence in an agent-scope benchmark.

So what prior theory misses: An evaluator-only assurance checklist misses sampling control; information design already provides the explanation.

Classification: DOMAIN_TRANSFER. Demote to an audit-design application. Do not rename selective evidence as a breakthrough.

No absence-of-prior-work proof. Partial inspection cannot show that an entire work lacks an extension.
