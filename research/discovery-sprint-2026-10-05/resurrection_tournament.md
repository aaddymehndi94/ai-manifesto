rating. The first-stage map below does not promote any branch to a public concept.

is not a proposition-level refutation. Conversely, adding known nodes to a known

## Rules for the next tournament stage

1. Finish the sharpening contrast before ratings.
2. Compare actual propositions from five primary works, including same graph,
   outcome, distinguishing prediction and intervention.
3. Mutate strong known results: change the beneficiary, outcome, missing resource,
   timing, strategic actor, comparison distribution or institutional response.
4. Preserve failed children with the exact reason. A useful benchmark is allowed
   to survive as engineering work while being rejected as the intellectual center.
5. Add post-court mutation results and finalists here before an AAA decision.

## Benefit is part of the mechanism

Shared recovery can pool complementary resources. New representation can reveal
previously underestimated capability. Accurate abstention memory can make
replacement safer. Coordinated rapid response can improve accessibility. None of
these is a mere safeguard: the same structure can change sign under the stated
conditions. A theory that calls every delegation increase harmful fails this
tournament.
