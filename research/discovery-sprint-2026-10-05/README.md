## Order of work

**Blue-team checkpoint complete; no winner selected.** A user intervention on 2026-10-05 paused
pruning and additional novelty courts. The dated [emergence protocol](emergence/protocol.md)
superseded the later steps below until the [checkpoint gate](emergence/checkpoint-gate.json).
All 120 sharpened candidates and
320 raw propositions are preserved. Prior verdicts remain process history, not
exclusions from compound construction. No public v0.5 changes are authorized.

1. Read the baseline and reconstruct its intellectual decisions.
2. Build a mutation graph over all old candidates; distinguish inherited nodes
   from possibly new interactions, outcomes, predictions, and interventions.
3. Generate at least 300 new propositions through twenty distinct operators.
4. Sharpen before scoring; keep separate scientific and explanatory tracks.
5. Challenge roughly sixty candidates using actual nearest-neighbor propositions.
6. Mutate strong inherited seeds; develop fifteen causal/formal dossiers.
7. Run blind independent reviewer tasks on eight finalists, then compare disagreements.
8. Run bounded synthetic experiments after conceptual/prior-art screening.
9. Keep three to five programs only if warranted; an empty set is an acceptable result.

Novelty residue is what remains after inherited structure, outcomes, and predictions
are subtracted. Related vocabulary alone cannot convict a composition. Failure to
find a match cannot establish originality. Optimizers use simulated actors only.

Each screening decision must distinguish novelty from importance and tractability.
No magic aggregate score. No public claim changes before a reasoned decision.
