## Beneficial mirrors and controls

`beneficial_mirror` is a same-structure positive case. `countervailing_intervention` is a separate practical control or comparison, retained from the first drafting pass. They must not be treated as equivalent fields.

For instance, D4:I107 can improve a child's opportunities when an evidentiary profile reveals underestimated capability; a profile-free opportunity period is a countervailing intervention. D4:I183 can select apprenticeship-supporting firms when contracting recognizes expert production; changing procurement is an intervention. D4:I205 can build switching trust through certification while accountable plural certification constrains exclusion.

Some irreversible mechanisms have positive consequences through a different affected interest rather than by undoing the irreversible residue. D4:I151 preserves the distinction between lost care testimony and privacy protection from retrospective scrutiny. A positive mirror is not proof that the negative branch is benign or that either branch has been observed.

## Raw newness QA and superseded drafts

The main agent identified close baseline compositions before scoring. The original D4:I123 repeated the central consequence of SG-17 (`research/notes/systems-governance-prior-art.md:657`); the original D4:I136 repeated SG-25's review arrival/service process (`:665`). These were replaced under the same IDs and are preserved below as superseded drafts. This is pre-integration raw QA, not completed sharpening or novelty grading.

Superseded D4:I123, **Review time depends on others deadlines**:

> If an agent action is reversible until a counterparty deadline, then a principal permission to review is ineffective when institutions shorten that deadline faster than comprehension improves.

Old parents: I043/I054/I146. Variables: review latency, counterparty deadline, reversibility window. Original control: bind deadline floors to review needs and compare delayed commitment with automated response. Original claimed difference: “Places the control window under external institutions, rather than treating review burden as only an interface property.” That distinction does not go beyond SG-17.

The revised row instead concerns the intersection of institution-specific condition-validity windows. Each local review period and the final deadline can be sufficient, yet no joint snapshot remains valid long enough to review. It compares final-deadline extension against coordinated validity or frozen joint conditions. That is an added conditional composition to test, not a certified new result.

Superseded D4:I136, **Distributed review congestion**:

> If many agents request independent approval from the same expert pool, then each grant can stay below its review budget while aggregate arrival exceeds the pool capacity and causes formerly reviewable actions to expire.

Old parents: I054/I149. Variables: per-grant request cap, shared reviewer capacity, expiry. Original control: reserve admission capacity across grants and compare local caps with aggregate quotas. Original claimed difference: “Adds a shared resource constraint across separately valid budgets and predicts expiry rather than habitual assent.” SG-25 already includes institutional capacity and remedy decay.

The revised row instead concerns shared substitutes reserved by separately approved commitments. Its distinguishing comparison holds grants and review utilization fixed while the joint refusal-feasible set changes. The proposed predictor is residual substitute feasibility, not review arrival or approval count. Ordinary constraint composition and outside-option literature remain ancestors requiring later comparison.

D4:I150 was also made more explicit. Superseded wording:

> If several members each delegate their easiest social exchanges, then the remaining human encounters can exceed available repair capacity even when each person retains the same total contact time.

Easy-to-agent/hard-to-human migration is HS-C28's existing mechanism. The revised row adds an explicit repair-capacity threshold and predicts unresolved-conflict rates at matched human contact time. A contact-time-only displacement account would not predict that difference. No comparison against a richer existing relationship model has yet been made.
