# Release validation — 0.5.0

Date: 05 October 2026. Public research draft, not a completed scientific result.

## Executed checks

- `npm run build`: 25 static routes, PDF/share assets, strict built-artifact validation.
- `npm test`: research structure, canonical artifact/source agreement, analytic
  scalar controls, eight typed fixtures, and authority boundary tests.
- `npm run qa`: 25 desktop and 25 mobile route checks; mode change, sliders,
  actual benchmark selector, archive search, canonical citation clipboard,
  figure dialog dismissal, mobile menu dismissal, paper print, and no-JS reading.
- Browser result: zero page errors, broken local links, or page-level overflows
  in the tested configurations. Tested Chromium at 1440px and 390px, reduced motion.
- Printable PDF: 27 A4 pages in this environment. Figures load before export.
- Canonical data: 8 concepts, 3 principles, 23 registered fixture/paper claims,
  40 S/F source records, and a 76-node structured concept/evidence graph.

The homepage HTML is approximately 14 KB, CSS 33 KB, and JavaScript 8 KB before
compression. The full debate HTML is approximately 282 KB. These byte counts
are not a field performance score or Lighthouse certification.

## Reconciled audit findings

The source and generated website now use conditional behavior language,
“authenticated records” rather than “valid evidence,” and separate reviewer
streams rather than overstating reviewer independence. Principles have their
own canonical routes. Paper-local IDs are registered, disambiguated from fixture
IDs, and preserve old aliases. Page metadata distinguishes the paper from other
web pages and selects relevant citations. S and F sources resolve through one
validated published register.

## Research requirements still open

No A-grade novelty or strong B is established. The central causal proposition
has prior art; only the narrow benchmark/interface extension remains B-proposed.
The conditional-influence contract is supporting synthesis.

No human study, strategic optimizing delegate, complete approval-closure
replication, cross-agent sensitivity experiment, calibrated societal model,
production-safe authorization service, or artificial patienthood result exists.
Initial seed-level exact source matching remains incomplete. Signed fixture
events do not establish real human observations, voluntary consent, independence,
legitimacy, or welfare.

The release is suitable for inspecting and criticizing a research proposal.
Publication as a definitive operating philosophy is not supported by the evidence.
See the final novelty audit, integrity review, and eight-audience success test.

## Deployment boundary

This report validates local artifacts. Deployment success requires the Sites
saved-version and deployment status plus an independent public HTTP check.
Those identifiers and observations belong in the subsequent deployment record.
